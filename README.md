# 🚀 PlayBot

Telegram мини-приложение с играми: **краш (ракетка)**, **слоты**, **мины** и **кейсы**.
Баланс в звёздах Telegram (⭐, виртуальные), кейсы с настоящими подарками Telegram, честная механика **provably fair** — каждый результат
можно проверить криптографически.

## Как устроена честность (provably fair)

1. Перед играми пользователю показывается **SHA-256 хэш** серверного сида —
   сервер уже «зафиксировал» свою случайность и не может её подменить.
2. Результат каждой игры = `HMAC-SHA256(server_seed, "client_seed:nonce:i")`.
3. В любой момент можно **сменить сид** — старый раскрывается, и все прошлые
   игры пересчитываются вручную и сверяются.

Преимущество площадки честно указано: краш и мины — 4% (RTP 96%),
слоты — RTP ~93.7%, кейсы — RTP 87–92%.

## Структура

```
bot/       — Telegram-бот (aiogram), кнопка открытия мини-аппа
server/    — FastAPI: игровая логика, provably fair, SQLite
webapp/    — фронтенд мини-аппа (HTML/CSS/JS)
```

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполните BOT_TOKEN и WEBAPP_URL

# API + мини-апп
uvicorn server.main:app --host 0.0.0.0 --port 8080

# бот (в отдельном терминале)
python -m bot.main
```

Переменные окружения читаются из окружения процесса — экспортируйте их
перед запуском (`export $(grep -v '^#' .env | xargs)`).

### Настройка в Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите `BOT_TOKEN`.
2. Разместите сервер на публичном HTTPS-домене (для теста — `ngrok http 8080`).
3. Укажите этот URL в `WEBAPP_URL`.
4. Запустите бота, отправьте `/start` — появится кнопка «Играть».

### Локальная разработка без Telegram

Установите `DEV_MODE=1` — API будет принимать запросы без подписи Telegram
(тестовый пользователь), мини-апп можно открыть в обычном браузере:
<http://localhost:8080>.

## Игры

| Игра | Описание | Возврат игроку |
|------|----------|----------------|
| 🚀 Краш | Множитель растёт, забери до взрыва | 96% |
| 🎰 Слоты | 3 барабана, выплаты до ×500 | ~93.7% |
| 💣 Мины | Поле 5×5, открывай ячейки, не попади на мину | 96% |
| 🎁 Кейсы | Бронзовый / Серебряный / Золотой с подарками | 87–92% |

## Важно

Сейчас в приложении **только виртуальные монеты** — без депозитов и вывода.
Подключение реальных платежей/призов требует решения юридических вопросов
(лицензирование азартных игр, правила Telegram для Stars) — не подключайте
реальные деньги, пока эти вопросы не решены.
